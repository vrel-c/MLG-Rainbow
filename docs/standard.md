# 通常版について
**MLG Rainbow** <small>（通常版）</small>のフォルダ構造、および基本的な利用方法についてのマニュアルです。

## インポート後のフォルダ構造
通常版が正常にインポートされている場合、`Assets` フォルダ内に以下のフォルダ構造が生成されます。

```text
Assets/
└── VRElectroCenter/
    └── MLG_Rainbow/             <- パッケージのルートフォルダ
        └── Data/
            ├── Material/        <- サンプルマテリアル
            │   └── Texture/     <- サンプル用テクスチャ
            └── Shader/          <- シェーダー本体
                ├── Editor/      <- カスタムGUI
                └── Includes/    <- 共通関数・変数ファイル
```
* **`MLG_Rainbow/`**
  * 本パッケージのルートフォルダです。このフォルダ直下に、表示サンプルのPrefabが含まれています。
* **`MLG_Rainbow/Data/`**
  * シェーダー本体や、サンプル用のデータ（マテリアル、テクスチャなど）が格納されています。
  * 通常、このフォルダ内のファイルを直接編集・変更・移動する必要はありません。

## シェーダーの利用方法（初心者向け）

> [!NOTE]
> Unityでのマテリアル作成やシェーダー割り当ての操作に**慣れている方は、このセクションを読み飛ばして**次の「マテリアルの設定項目」へお進みください。

### 1. マテリアルの作成と適用
1. **Project** ウィンドウの空いている場所を右クリックします。
2. メニューから **Create > Material** を選択し、任意の名称（例: `MyRainbowMaterial` 等）でマテリアルを新規作成します。
3. 作成したマテリアルを選択し、**Inspector** ウィンドウ最上部の **Shader** ドロップダウンをクリックします。
4. リストから **VRElectroCenter > MLG_Rainbow** を選択します。

> [!TIP]
> リスト内の MLG_Rainbow_Transparent や MLG_Rainbow_Outline 等の個別シェーダーは、GUIの自動切り換え用です。
> 新規作成時は、基本的に **MLG_Rainbow** を選択してください。

### 2. マテリアルの設定
1. 必要に応じて **描画モード** や **発行色**、**発光マスク** などを設定します。
2. 詳細な設定内容については、次の「マテリアルの設定項目」を参照してください。

### 3. オブジェクトへの適用
1. 作成したマテリアルを、表示したいオブジェクトの **Mesh Renderer** または **Skinned Mesh Renderer** の **Materials** に割り当てます。
2. または、マテリアルをオブジェクトへ直接ドラッグ＆ドロップして適用することもできます。

## マテリアルの設定項目

本シェーダーを適用したマテリアルの **Inspector** ウィンドウに表示される設定項目の一覧です。

### 描画設定

* **描画モード**
  * オブジェクトの描画方法を指定します。
  * **不透明**：通常の不透明オブジェクトとして描画します。
  * **カットアウト**：テクスチャのアルファ値を基準に切り抜き表示を行います。
  * **半透明**：アルファ値に応じて半透明表示を行います。

* **Cull Mode**
  * ポリゴンのどちらの面を描画するかを指定します。
  * **両面を描画 (Off)**：表面・裏面の両方を描画します。
  * **裏面のみ描画 (Front)**：表面を描画せず、裏面のみを描画します。
  * **表面のみ描画 (Back)**：裏面を描画せず、表面のみを描画します。通常はこちらを使用してください。

* **Z Write**
  * 深度バッファ（Zバッファ）へ書き込むかどうかを指定します。
  * 描画モードに応じて適切な値が自動的に設定されるため、通常は変更する必要はありません。
  * 半透明オブジェクトの描画方法を調整したい場合など、必要に応じて変更してください。

* **Render Queue**
  * オブジェクトを描画する順番を指定します。
  * 描画モードに応じて適切な値が自動的に設定されるため、通常は変更する必要はありません。
  * 他のオブジェクトとの描画順を調整したい場合は、必要に応じて変更してください。特に、半透明オブジェクト同士が重なる場合に有効です。

### 基本設定

* **カラー**
  * オブジェクト全体の色を設定します。
  * テクスチャの色味を調整する場合にも使用できます。

* **テクスチャ**
  * オブジェクトに表示するテクスチャを指定します。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

### ライティング設定

* **ライティング方式**
  * シェーダー全体のライティング方式を選択します。
  * **Unlit**：シーン内のライトの影響を受けず、一定の明るさで表示されます。
  * **Lit**：シーン内のライトの影響を受けて描画されます。

* **陰影の明るさ**
  * **ライティング方式** が **Lit** の場合にのみ表示されます。
  * 陰影の強さを調整します。値を大きくするほど影の影響が少なくなり、全体的に明るく均一な見た目になります。

* **明るさの下限**
  * **ライティング方式** が **Lit** の場合にのみ表示されます。
  * 暗い場所での「最低限の明るさ」を設定します。値を大きくするほど、影の部分の明るさの下限が引き上げられます。
 
### ノーマルマップ設定

* **マップ**
  * ノーマルマップとして使用するテクスチャを指定します。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

* **強度**
  * ノーマルマップによる凹凸表現の強さを調整します。
  * 数値を大きくするほど、凹凸表現が強調されます。

* **マスク**
  * ノーマルマップを適用する範囲を指定するマスクテクスチャを指定します。
  * 白い部分ほど強く適用され、黒い部分には適用されません。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

 ### マットキャップ設定

* **マップ**
  * マットキャップとして使用するテクスチャを指定します。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

* **強度**
  * マットキャップによる質感表現の強さを調整します。
  * 数値を大きくするほど、マットキャップの影響が強くなります。

* **マスク**
  * マットキャップを適用する範囲を指定するマスクテクスチャを指定します。
  * 白い部分ほど強く適用され、黒い部分には適用されません。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

### 発光設定

* **発光色**
  * 発光部分の色を設定します。
  * グラデーション設定を使用する場合、基準となる色として使用されます。

* **発光マスク**
  * 発光を適用する範囲を指定するマスクテクスチャを指定します。
  * 白い部分が強く発光し、黒い部分は発光しません。
  * テクスチャのタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

* **発光の強さ**
  * 発光の明るさを調整します。
  * 数値を大きくするほど、発光表現が強くなります。

### カラーアニメーション設定

* **色相遷移の速度**
  * 色相が変化する速度を設定します。
  * 0に設定すると色相変化を行わず、発光色を固定した状態になります。
  * 値を大きくするほど、色の変化が速くなります。
 
* **色相変化の下限値**
  * 発光色を基準とした、色相変化範囲の下限を設定します。
  * 値を変更することで、カラーアニメーションで使用する色の範囲を調整できます。
 
* **色相変化の上限値**
  * 発光色を基準とした、色相変化範囲の上限を設定します。
  * 値を変更することで、カラーアニメーションで使用する色の範囲を調整できます。

* **遷移の向きを反転**
  * 色相が変化する方向を反転します。
  * 色が変化する順番を逆にしたい場合に使用します。

* **ピンポン再生（往復ループ）**
  * 色相変化を往復するように再生します。
  * 有効にすると、色が一定方向に変化し続けるのではなく、設定した範囲内を行き来するようになります。
 
### グラデーション設定

* **グラデーションを有効化**
  * オブジェクトのローカル座標を基準としたグラデーション処理を有効化します。
  * 有効時のみ以下の輪郭線設定が表示され、マイナス側の色 → 発光色 → プラス側の色の順で負方向から正方向へ連続的に色が補間されます。<br/>
    <small>※ 本パラメータ（Toggle）は内部的にシェーダーバリアントを切り替えるため、Unityのアニメーション（Animation）から動的にON/OFFを切り替えることはできません。</small>

* **グラデーションの原点（ローカル座標）**
  * グラデーションの基準となる位置を指定します。
  * 初期状態ではオブジェクトのローカル原点が基準になります。
  * 値を変更することで、グラデーションの中心位置を移動できます。

* **グラデーションの方向**
  * グラデーションが変化する方向をベクトルで指定します。
  * XYZの値を変更することで、任意の方向へグラデーションを設定できます。

* **グラデーションの幅**
  * 色変化のスケールを調整します。
  * 小さい値では変化が密になり、大きい値では変化が緩やかになります。
  * オブジェクトのスケールが大きい場合は、この値を大きくすることで、正方向・負方向の距離関係を維持できます。

* **グラデーションの緩急（カーブ）**
  * 色の変化具合を調整します。
  * 値を変更することで、中央の色を強調したり、端の色を強調したグラデーションに調整できます。

* **マイナス側の色**
  * グラデーション方向のマイナス側に適用される色を指定します。

* **プラス側の色**
  * グラデーション方向のプラス側に適用される色を指定します。

### 輪郭線設定

* **輪郭線を有効化**
  * 輪郭線の描画を有効化します。
  * 有効時のみ、以下の輪郭線設定が表示されます。

* **輪郭線マスク**
  * 輪郭線を適用する範囲を指定するマスクテクスチャを指定します。
  * 白い部分に輪郭線が適用され、黒い部分には適用されません。

* **輪郭線の太さ**
  * 輪郭線の太さを調整します。
  * 値を大きくするほど、輪郭線が太く表示されます。

* **輪郭線の色**
  * 輪郭線の色を設定します。

* **輪郭線の発光の強さ**
  * 輪郭線の発光量を調整します。
  * 値を大きくするほど、輪郭線が明るく発光します。

* **輪郭の押し出し補正**
  * 輪郭線を外側へ押し出す方向を補正します。
  * 値を変更することで、球体などの丸い形状や複雑な形状で輪郭線の見え方を調整できます。


### 高度な設定 (ADVANCED)

> [!TIP]
> 描画や色補間に関する詳細な設定です。<br/>一部の項目は有効化することで処理負荷が増加するため、用途に応じて調整してください。

::: details 詳細

* **切り抜きの閾値**
  * **描画モード** が **カットアウト** の場合にのみ表示されます。
  * 透明部分を判定する閾値を設定します。
  * 値を大きくするほど、表示される範囲が狭くなります。

* **落とす影の濃さ**
  * **描画モード** が **半透明** の場合にのみ表示されます。
  * オブジェクトが落とす影の濃さを調整します。
  * 値を小さくするほど、影が薄くなります。

* **\[高負荷\] 高品位カラーブレンドを有効化**
  * 各種色変化の補間方法を変更します。
  * 有効時のみ、下記の **色空間のブレンド率** を調整できます。

* **色空間のブレンド率（HSV - Oklch）**
  * HSVとOklchによる色補間の割合を設定します。
  * 値を小さくするとHSV寄り、値を大きくするとOklch寄りの色変化になります。

* **Enable GPU Instancing**
  * Unity標準の設定です。
  * 同一マテリアルを使用するオブジェクトを効率よく描画できる場合があります。

* **Double Sided Global Illumination**
  * Unity標準の設定です。
  * ライトベイク時に両面へグローバルイルミネーションを適用するかを設定します。

:::
