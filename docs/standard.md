# 通常版について
**MLG Rainbow** <small>（通常版）</small>のフォルダ構造、および基本的な利用方法についてのマニュアルです。

## インポート後のフォルダ構造
通常版が正常にインポートされている場合、`Assets` フォルダ内に以下のフォルダ構造が生成されます。

```text
Assets/
└── VRElectroCenter/
    └── MLG_Rainbow/             <- パッケージのルートフォルダ
        └── Data/
            ├── Material/        <- サンプルマテリアル
            │   └── Texture/     <- サンプル用テクスチャ
            └── Shader/          <- シェーダー本体
                ├── Editor/      <- カスタムGUI
                └── Includes/    <- 共通関数・変数ファイル
```
* **`MLG_Rainbow/`**
  * 本パッケージのルートフォルダです。このフォルダ直下に、表示サンプルのPrefabが含まれています。
* **`MLG_Rainbow/Data/`**
  * シェーダー本体や、サンプル用のデータ（マテリアル、テクスチャなど）が格納されています。
  * 通常、このフォルダ内のファイルを直接編集・変更・移動する必要はありません。

## シェーダーの利用方法（初心者向け）

> [!NOTE]
> Unityでのマテリアル作成やシェーダー割り当ての操作に**慣れている方は、このセクションを読み飛ばして**次の「マテリアルの設定項目」へお進みください。

### 1. マテリアルの作成と適用
1. **Project** ウィンドウの空いている場所を右クリックします。
2. メニューから **Create > Material** を選択し、任意の名称（例: `MyRainbowMaterial` 等）でマテリアルを新規作成します。
3. 作成したマテリアルを選択し、**Inspector** ウィンドウ最上部の **Shader** ドロップダウンをクリックします。
4. リストから **VRElectroCenter > MLG_Rainbow** を選択します。

> [!TIP]
> リスト内の MLG_Rainbow_Transparent や MLG_Rainbow_Outline 等は、GUIが自動で切り替えるためのものです。マテリアルの新規作成時には、基本的には MLG_Rainbow を選択してください。

### 2. マテリアルの設定
1. 必要に応じて **描画モード** や **発行色**、** 発光マスク ** などを設定します。
2. 詳細な設定内容については、次の「マテリアルの設定項目」を参照してください。

### 3. オブジェクトへの適用
1. 作成したマテリアルを、表示したいオブジェクトの **Mesh Renderer** または **Skinned Mesh Renderer** の **Materials** に割り当てます。
2. または、マテリアルをオブジェクトへ直接ドラッグ＆ドロップして適用することもできます。

## マテリアルの設定項目

本シェーダーを適用したマテリアルの **Inspector** ウィンドウに表示される設定項目の一覧です。
