# MLG Rainbow 利用マニュアル

## 概要

**MLG Rainbow (Mesh Local Glow Rainbow)** は、メッシュのローカル座標を基準に滑らかなグラデーションと色相アニメーションを生成する機能を持つ、Unity／VRChat向けシェーダーです。

UVレイアウトに依存せず、オブジェクト全体をシームレスに彩ることができます。アバターの衣装やアクセサリーはもちろん、ワールド内の装飾・演出など、幅広いシーンで活躍します。
