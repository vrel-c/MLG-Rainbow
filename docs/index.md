# MLG Rainbow 利用マニュアル

## 概要

**MLG Rainbow** は、（Mesh Local Glow Rainbow）は、メッシュのローカル座標を基準としてグラデーション描画を行い、時間経過による色相変化を組み合わせることで、シームレスな虹色発光を実現する Unity／VRChat向けシェーダーです。

UVレイアウトに依存せず、オブジェクト全体を連続的に彩ることができるため、アバターの衣装やアクセサリー、ワールド内の装飾・演出など、さまざまな用途で利用できます。
