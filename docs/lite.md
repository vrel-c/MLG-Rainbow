# Lite版について
**MLG Rainbow Lite版** のフォルダ構造、および基本的な利用方法についてのマニュアルです。

## インポート後のフォルダ構造
Lite版が正常にインポートされている場合、`Assets` フォルダ内に以下のフォルダ構造が生成されます。

```text
Assets/
└── VRElectroCenter/
    └── MLG_Rainbow_Lite/  <- パッケージのルートフォルダ
        └── Data/              <- シェーダーファイル・サンプルマテリアル等
```
* **`MLG_Rainbow_Lite/`**
  * 本パッケージのルートフォルダです。このフォルダ直下に、表示サンプルのPrefabが含まれています。
* **`MLG_Rainbow_Lite/Data/`**
  * シェーダー本体や、サンプルPrefab用のマテリアルが格納されています。
  * 通常、このフォルダ内のファイルを直接編集・変更・移動する必要はありません。

## シェーダーの利用方法（初心者向け）

> [!NOTE]
> Unityでのマテリアル作成やシェーダー割り当ての操作に**慣れている方は、このセクションを読み飛ばして**次の「マテリアルの設定項目」へお進みください。

### 1. マテリアルの作成と適用
1. **Project** ウィンドウの空いている場所を右クリックします。
2. メニューから **Create > Material** を選択し、任意の名称（例: `MyRainbowMaterial` 等）でマテリアルを新規作成します。
3. 作成したマテリアルを選択し、**Inspector** ウィンドウ最上部の **Shader** ドロップダウンをクリックします。
4. リストから **VRElectroCenter > MLG_Rainbow_Lite** を選択します。

### 2. マテリアルの設定
1. 必要に応じて **Base Color** や **Emission Color** などを設定します。
2. 詳細な設定内容については、次の「マテリアルの設定項目」を参照してください。

### 3. オブジェクトへの適用
1. 作成したマテリアルを、表示したいオブジェクトの **Mesh Renderer** または **Skinned Mesh Renderer** の **Materials** に割り当てます。
2. または、マテリアルをオブジェクトへ直接ドラッグ＆ドロップして適用することもできます。

## マテリアルの設定項目

本シェーダーを適用したマテリアルの **Inspector** ウィンドウに表示される設定項目の一覧です。

> [!TIP]
> Lite版はカスタムGUI非搭載のため、Unityの標準プロパティ形式で設定項目が表示されます。

### Basic Settings（基本設定）

* **Base Color** 
  * 非発光部分の基礎色を指定します。
  * Base Mapと乗算され、最終的な表示色になります。
* **Base Map**
  * 非発光部分のテクスチャを設定します。
  * 画像のタイリング（Tiling）およびオフセット（Offset）の調整が可能です。

### Emission Settings（発光設定）
* **Emission Color**
  * エミッション（発光表現）の基準色を指定します。
  * マスク適用部分の色に影響します。

* **Emission Mask**
  * エミッションを適用する領域を制御するマスクテクスチャです。
  * 画像のタイリング（Tiling）およびオフセット（Offset）の調整が可能です。
  * 白に近いほど強く発光し、黒に近いほど発光しません。

* **Invert Mask**
  * マスクの白黒の扱いを反転します。
  * 黒領域を発光対象にする場合に使用します。

* **Emission Strength**
  * エミッションの明るさを調整します。
  * 数値を大きくすると発光がより強くなります。

### Color Animation（色相アニメーション）

* **Hue Shift Speed**
  * 時間経過に応じて色相を変化させる速度を指定します。
  * 0を指定した場合、色相の変化は行われません。

### Gradient Settings（グラデーション設定）

* **Enable Gradient**
  * オブジェクトのローカル座標を基準としたグラデーション処理を有効化します。
  * 有効時は、Negative Direction Color → Emission Color → Positive Direction Color の順で、負方向から正方向へ連続的に色が補間されます。<br/>
    <small>※ 本パラメータ（Toggle）は内部的にシェーダーバリアントを切り替えるため、Unityのアニメーション（Animation）から動的にON/OFFを切り替えることはできません。</small>

* **Gradient Origin**
  * グラデーションの基準となる位置を指定します。
  * 初期状態ではオブジェクトのローカル原点が基準になります。
  * 値を変更することで、グラデーションの中心位置を移動できます。

* **Gradient Axis**
  * 色変化を行う方向（X / Y / Z）を指定します。
  * 指定した軸方向に沿ってグラデーションが発生します。

* **Gradient Distance**
  * 色変化のスケールを調整します。
  * 小さい値では変化が密になり、大きい値では変化が緩やかになります。
  * オブジェクトのスケールが大きい場合は、この値を大きくすることで、正方向・負方向の距離関係を維持できます。

* **Negative Direction Color**
  * 指定した軸の負方向側に適用される色を指定します。

* **Positive Direction Color**
  * 指定した軸の正方向側に適用される色を指定します。

::: warning 注意：Unity標準設定について
マテリアル下部に表示される **Render Queue などのUnity標準設定（Advanced Options）は、基本的には変更しないでください。**<br/>
本シェーダー（Lite版）はRender Queue = Geometryを前提とした描画構成になっているため、値を変更すると描画順やブレンド挙動が崩れ、意図した表示にならなくなる場合があります。ただし、環境に合わせて `Enable GPU Instancing` を有効化するなどの調整を行う場合については問題ありません。
:::
